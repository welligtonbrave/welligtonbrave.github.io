Metodologia e Transparência Eleitoral

O VotoBrasil 2026 adota como fonte primária os boletins de urna eletrônica e dados oficiais consolidados pelo Tribunal Superior Eleitoral (TSE).

1. Regra Constitucional de Votos Válidos

Conforme o Artigo 77, § 2º da Constituição Federal de 1988, são computados para fins de eleição majoritária exclusivamente os votos válidos nominais. Votos em branco e votos nulos não são incluídos no cálculo dos percentuais dos concorrentes.

2. Totalização das Urnas Eletrônicas

Os resultados refletem a apuração de 100,00% das seções eleitorais do território nacional e do exterior, processadas pelo Sistema de Totalização e Divulgação de Resultados (DivulgaCandContas) do TSE em 4 de outubro de 2026.

3. Arquitetura Estática para GitHub Pages

Este portal foi projetado para execução 100% estática sem requisições a servidores dinâmicos ou bancos de dados locais. Compatível com publicação instantânea no GitHub Pages, Vercel ou Netlify.
